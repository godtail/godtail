I’m a founder and builder exploring how AI can help small teams build more ambitious products.
Currently, I’m building [HiTest](https://hitest.ai/) — an AI QA agent for teams that ship faster than they can test. It turns everyday user flows into repeatable browser tests, without writing test code.
- Discover what to test by letting AI explore your app.
- Start with what you have: plain-English instructions, recordings, or existing Excel test cases.
- Keep testing as you ship: schedule real-browser runs and investigate failures with screenshots and recordings.
More time turning ideas into products. Less time repeating the same checks.
